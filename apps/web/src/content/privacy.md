# Política de privacidade — versão de testes

O SIG Paramirim utiliza a autenticação Google para criar e proteger o acesso à plataforma. Os dados básicos da conta são usados para identificação, controle de permissões e funcionamento do perfil.

Esta versão é um texto provisório para validação da interface. A política jurídica definitiva será publicada após revisão específica de privacidade, segurança e conformidade aplicável.
