# Termos de uso — versão de testes

O SIG Paramirim é uma plataforma de visualização, organização e divulgação de informações territoriais. Nesta versão de testes, os conteúdos são disponibilizados para avaliação da interface e não substituem documentos oficiais, laudos, licenças ou projetos de engenharia.

O usuário deve utilizar os dados de forma responsável, respeitar as fontes indicadas e não interpretar mapas ou indicadores isolados como garantia de segurança, disponibilidade hídrica ou risco.
